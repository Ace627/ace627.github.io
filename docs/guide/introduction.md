# 简介

云在青天，禾在土；管理在心，事在术。

云禾是一套面向前端开发者进阶全栈的企业级后台管理系统模板。

与市面上绝大多数前后端分离、多语言混编的管理系统不同，云禾以 pnpm workspace 的 Monorepo 方式将前端与后端纳入同一仓库、统一 TypeScript 语言、同一套工程化体系，让前端开发者无需跨越语言鸿沟即可独立交付完整后台系统。

## 架构差异

常规后台管理系统的典型架构：前端 Vue/React 一个仓库，后端 Java/Go 另一个仓库，两套语言、两套 IDE、两套调试方式。前端开发者想要摸到后端，得先趟过语言关、框架关、环境关。

云禾的做法截然不同：

| 维度     | 常规架构                        | 云禾                                     |
| -------- | ------------------------------- | ---------------------------------------- |
| 代码组织 | 前后端分仓库，各自维护          | Monorepo 单仓库，一次 install 到位       |
| 开发语言 | 前端 TS + 后端 Java/Go 等       | 全栈 TypeScript，零语言切换              |
| 后端框架 | Spring Boot / Gin，学习曲线陡峭 | NestJS，模块化 / 装饰器与 Vue 3 一脉相承 |
| 类型共享 | 前后端各自定义，手写接口文档    | 共享 TS 类型定义，接口即文档             |
| 定位     | 拿来即用的架子，代码即黑盒      | 学习系统，每模块都是前后端协作范例       |
| 目标用户 | 后端主导的全栈团队              | 想进阶全栈的前端开发者                   |

## 核心功能

云禾的功能模块不满足于「有」，而追求「可学」。每个模块都是精心编排的前后端协作范例——前端代码怎么写、接口怎么设计、数据库怎么建表、权限怎么校验，全部连通成一条可追踪的链路。前端开发者可以逐个模块对照学习，从 CRUD 入门到消息队列进阶，逐步建立全栈思维。

### 系统管理

| 模块     | 功能                                         | 学习路径                      |
| -------- | -------------------------------------------- | ----------------------------- |
| 用户管理 | 增删改查、重置密码、角色分配、头像设置       | 入门 CRUD 全链路贯通          |
| 角色管理 | 角色权限分配、数据权限、角色编码管理         | RBAC 多对多关联与权限装饰器   |
| 菜单管理 | 目录 / 菜单 / 按钮三级粒度，支持外链、iframe | 数据 → 路由 → 侧边栏动态闭环  |
| 字典管理 | 字典类型 + 字典数据两级结构                  | 后端缓存策略 + 前端组合式封装 |

### 系统监控

| 模块     | 功能                           | 学习路径                         |
| -------- | ------------------------------ | -------------------------------- |
| 服务监控 | 实时 CPU / 内存 / 磁盘         | Node.js os 模块与系统信息采集    |
| 缓存监控 | Redis 实例、内存用量、Key 管理 | Redis INFO 命令与 ioredis 实操   |
| 健康检查 | /live /ready 双探针            | NestJS Terminus 容器探针集成     |
| 在线用户 | 活跃会话查看，强制下线         | JWT 状态管理与 Redis 会话存取    |
| 定时任务 | BullMQ 动态调度，暂停恢复      | Job / Queue / Worker / Scheduler |
| 操作日志 | 全接口记录，IP 归属地解析      | NestJS Interceptor 拦截器模式    |
| 登录日志 | 登录成功 / 失败全量记录        | 认证流程 Guard 层切面记录        |

### 文件上传

从单文件到分片、从断点续传到秒传，循序渐进覆盖真实生产场景：

| 能力       | 场景                     | 核心技术                         |
| ---------- | ------------------------ | -------------------------------- |
| 单文件上传 | 常规小文件，10MB 以下    | FormData + Multer 基础链路       |
| 分片上传   | 大文件切分，并发上传     | SparkMD5 + 并发控制 + 进度追踪   |
| 断点续传   | 中断恢复，不浪费已传分片 | 分片检测 + 断点位置恢复          |
| 秒传机制   | 已存在文件零等待         | MD5 唯一标识 + pipeline 流式合并 |

## 设计理念

云禾不追求花哨的技术堆砌，而专注于让前端开发者真正看懂、学会、用上。每一个模块都经过精心设计，代码注释完整，类型定义清晰，拒绝「源码即天书」。不争云端之名，只守禾下之实；不炫繁复之术，但求至简之理。
