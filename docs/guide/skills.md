# 技能推荐

## crud-generator

`crud-generator` 是专为本项目量身打造的 AI SKILL，用于自动生成全栈 CRUD 代码，通过预设的「快速生成增删改查」提示词即可一键调用；它覆盖后端 5 层（Entity、DTO、Service、Controller、Module）和前端 3 层（Types、API Request、列表页），支持标准单表、树形菜单、主从字典三种模式，严格遵循项目的 TypeORM 规范、Vue3 组件约定（ProTable、ProSearch、DictTag 等）、权限标识格式和 import 排序规则，生成完成后还会自动提示 Entity 导出注册、类型桶导出、动态路由菜单配置等手动步骤，大幅降低重复编码工作，确保代码风格一致性。
